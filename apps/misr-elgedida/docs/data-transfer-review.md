# مراجعة بيانات الفرع قبل النقل

الحالة: لم يتم نقل أو نسخ أي بيانات إنتاج إلى هذا المشروع.

## قواعد أساسية
- لا تتصل هذه النسخة بقاعدة الإنتاج.
- لا تحفظ كلمات مرور أو مفاتيح API أو بيانات شخصية في GitHub.
- لا يبدأ النقل إلا بعد مراجعة قائمة البيانات والموافقة الصريحة عليها.
- لا يتم تخمين الفرع الصحيح للسجلات التي لا تحمل فرعًا واضحًا.

## جرد أولي من المراجعة السابقة
الأرقام التالية ملخصات عددية فقط وليست نسخة احتياطية:

| الجدول | مدينة المستقبل | مصر الجديدة | غير محدد الفرع |
|---|---:|---:|---:|
| العملاء | 12 | 0 | 0 |
| الموظفون | 11 | 0 | 1 |
| قطع الغيار | 21 | 0 | 4 |
| أوامر الشغل | 11 | 0 | 0 |
| الفواتير | 10 | 0 | 0 |
| المصروفات | 20 | 0 | 0 |

هذه الأعداد تحتاج إلى إعادة تحقق قبل أي قرار نقل، ولا تعني أن سجلات مصر الجديدة غير موجودة خارج الجداول المذكورة.

## قائمة المراجعة المطلوبة
- [ ] العملاء وبيانات الاتصال
- [ ] السيارات وربطها بالعملاء
- [ ] أوامر الشغل وحالاتها
- [ ] الفواتير وبنودها وطرق الدفع
- [ ] الأصناف والكميات وتكلفة/سعر البيع
- [ ] الزيوت والفلاتر والمخازن المنفصلة
- [ ] المصروفات والمستندات
- [ ] الموظفون والحضور والصلاحيات
- [ ] سجلات العمليات والأرشيف
- [ ] أرقام المستندات والتسلسل
- [ ] المرفقات والصور، إن وجدت
- [ ] العلاقات بين الجداول وسلامة الأرقام الإجمالية

## قرار النقل
يجب اعتماد قائمة صريحة لكل جدول: (ينقل كاملًا / ينقل جزءًا محددًا / لا ينقل)، مع التحقق من العدد قبل النقل وبعده. لا يتم دمج السجلات غير محددة الفرع تلقائيًا.
